# QA Wolf landing page example

A small [Next.js](https://nextjs.org/) site that shows a QA Wolf landing page. It deploys to Netlify at https://zen-torvalds-8e5c2a.netlify.app.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

The page lives in `pages/index.js`. Styles live in `styles/`.
